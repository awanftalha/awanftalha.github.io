## /* Four jobs, start to finish */

1. **Clock in.** From the lock screen, kept in view by a Live Activity, fixed in a sheet.
2. **Apply for leave.** Balance first, then dates, then who else is off.
3. **Approve.** Bilal decides from the notification, or opens it for the full picture.
4. **First week.** A calm welcome, Face ID to sign, and a day one of people.

## /* Where it stands */

Shipped on iOS and Android. Liquid Glass for the controls, HX Insight for the content.

All employees use it.

Android uses the same look as iOS, built with custom design libraries, while the behaviour follows Android conventions.
