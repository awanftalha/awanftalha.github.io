## /* When it fails, nothing is lost */

Most of the screens in this project are not the happy path. Every failure has a cause, a reassurance and a way out.

1. **Reassure first.** Say what's safe before asking for a retry.
2. **Warning, not error.** When the system fails, the user didn't. Amber, not red.
3. **No dead buttons.** Blocked buttons say what's left, like "2 issues to fix".

## /* Outcome */

Shipped and in use, for a client building software for home-service companies: a web app for the office and an iOS app for the crew, on one design system.
